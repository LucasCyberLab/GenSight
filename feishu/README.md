# 飞书共享包使用说明

本目录用于把元晟传媒规划同步到飞书，供同事查看和评论。

## 推荐方式

1. 在飞书中新建一个文档，命名为：`元晟传媒业务与自媒体运营规划 v2026-07-06`。
2. 将 [元晟传媒业务与自媒体运营规划-飞书共享版.md](./元晟传媒业务与自媒体运营规划-飞书共享版.md) 的正文复制到飞书文档。
3. 将 [双人工作推进计划-飞书共享版.md](./双人工作推进计划-飞书共享版.md) 作为执行页，放在主文档后面或单独建一个飞书文档。
4. 将 [企业介绍与交付标准-飞书共享版.md](./企业介绍与交付标准-飞书共享版.md) 作为对外介绍和报价标准页，供同事重点评论。
5. 将 [商业项目方案设计-飞书共享版.md](./商业项目方案设计-飞书共享版.md) 作为崇明、小马宝莉、Teddy、华南茶养等策略型案例和 BP / 政府汇报方案服务评审页。
6. 如需评审闲鱼试点，将 [闲鱼渠道试点-飞书共享版.md](./闲鱼渠道试点-飞书共享版.md) 作为单独评审页。
7. 将 [飞书评论标注清单.md](./飞书评论标注清单.md) 作为评审说明放在文档最前或作为单独附件。
8. 给同事开“可评论”权限，不开“可编辑”权限。
9. 同事只在飞书里用评论提出修改建议；由你统一决定是否修改原文档。

## 权限建议

- 你：可编辑
- 同事：可评论
- 外部人员：默认无权限；如需查看，只给指定人可阅读

## 评论规则

评论建议用这个格式：

```text
【建议类型】业务范围 / 定价 / 宣传策略 / 多淼协作 / 案例公开 / 其他
【原文位置】例如：3.2 多淼联合项目价
【修改建议】写清楚建议改成什么
【理由】为什么要改
```

## 不建议在飞书直接多人编辑的原因

当前规划涉及价格、合作分工、客户案例边界和多淼联合承接规则，多人直接改正文容易造成版本混乱。建议先走“评论评审”，由你统一改主文档。
