# 元晟传媒协同工作台 · 飞书多维表格搭建手册

目标：把网页工作台的全部协同功能搬进飞书，两人手机/电脑随时同步，数据不出公司，不依赖公网服务器，不依赖Howard Mac 常开。

## 方案：一个多维表格（Base）承载全部功能

网页工作台的本质是「几张共享表 + 勾选状态 + 一个交接流程」。飞书多维表格原生就是共享数据库，功能对照如下：

| 网页工作台模块 | 飞书实现 | 导入文件 |
| --- | --- | --- |
| 协同工作台（任务交接） | 数据表「任务交接」+ 看板视图 | `01-任务交接表.csv` |
| 启动准备（34 项） | 数据表「启动准备」+ 按负责人分组 | `02-启动准备清单.csv` |
| 基础校验（18 项） | 数据表「基础校验」 | `03-基础校验清单.csv` |
| 本周计划 / 今日推进 | 数据表「每日任务」（80 条已展开）+ 今日过滤视图 | `04-每日任务表.csv` |
| 询盘记录 | 数据表「询盘记录」+ 表单收集 | `05-询盘记录.csv` |
| 晚间复盘（五问） | 数据表「晚间复盘」+ 表单视图 | `06-晚间复盘.csv` |
| 总览仪表盘 | 多维表格「仪表盘」页 | 自动统计 |
| 文档库（20 个核心文档索引） | 数据表「文档库」+ 飞书云文档文件夹 | `07-文档库.csv` |
| 案例资产 | 数据表「案例库」+ 关联文档 + 包装状态 | `08-案例库.csv` |
| 自媒体发布计划 | 数据表「内容发布表」+ 平台/周期/状态视图 | `09-内容发布表.csv` |
| 业务范围与报价 | 数据表「产品与报价」+ 对外/渠道分视图 | `10-产品与报价表.csv` |
| 到点提醒 / @对方 | 多维表格「自动化」+ 群机器人 | 配置 |

---

## 第一步：创建多维表格并导入 10 张表（约 25 分钟）

1. 打开飞书 → 云文档 → 新建 → **多维表格**，命名「元晟传媒协同工作台」。
2. 对每个 CSV：点左上角「+ 添加数据表」→ **从本地导入** → 选择 `feishu-import/` 下对应文件 → 确认首行为字段名。
3. 建议按这个顺序导入：任务交接 → 每日任务 → 启动准备 → 基础校验 → 文档库 → 案例库 → 内容发布表 → 产品与报价 → 询盘记录 → 晚间复盘。
4. 导入后删掉默认生成的空表「数据表」，删掉询盘/交接表里的示例行。

导入后调整字段类型（点字段名 → 编辑字段）：

- 所有「状态」列 → **单选**（飞书会自动识别选项，给「已完成/已成交」设绿色，「进行中/待接手」黄色，「未成交/待补充」红色）
- 「负责人 / 执行人 / 发起人 / 接手人 / 跟进人 / 填写人」→ **人员** 字段（重新选一遍成员，这样才能 @提醒）
- 「日期 / 截止日期」→ **日期** 字段
- 「报价金额」→ **数字** 字段
- 「关联文档」→ 第一轮可先保留文本；等文档库链接补齐后，改成 **关联记录** 字段，关联「文档库」
- 「关联案例」→ 改成 **关联记录** 字段，关联「案例库」
- 「关联数据表」→ 保留文本即可，用于说明这个文档服务哪些表

## 第二步：为每张表建关键视图（约 10 分钟）

**任务交接表**（核心，替代网页版协同工作台）：

- 新建 **看板视图**，按「状态」分组，列顺序：待开始 → 进行中 → 待接手 → 待确认 → 待补充 → 已完成。拖卡片 = 网页版的状态流转。
- Howard推送任务 = 新增一行填「接手人：Brian」+ 状态「待接手」；Brian点开卡片改「进行中」，做完改「待确认」。

**每日任务表**：

- 新建 **表格视图**「今日任务」，筛选条件：日期 = 今天，按执行人分组 → 打开就是两人今日对照，等价网页版「今日推进」。
- 原表按「周次」分组，作为周计划总览。

**启动准备 / 基础校验**：

- 按「分类」分组即可；顶部加一个「完成率」统计（分组统计选「状态」字段）。

**询盘记录**：

- 新建 **表单视图**「询盘登记」，手机上 30 秒填完一条。
- 表格视图按「状态」分组，成交/未成交一目了然。

**晚间复盘**：

- 新建 **表单视图**「每日五问」，两人 18:00 各交一份。

**文档库**：

- 新建视图「待导入文档」：筛选 导入状态 = 待导入。
- 新建视图「敏感内部文档」：筛选 权限级别 = 敏感内部。
- 新建视图「对外可转发」：筛选 权限级别 = 公开可转发。
- 每导入一个飞书文档，把文档链接填回「飞书文档链接」，并把导入状态改为「已导入」。

**案例库**：

- 新建视图「收费案例优先」：筛选 收费属性包含 已收费，按优先级排序。
- 新建视图「待脱敏案例」：筛选 状态 = 待脱敏。
- 新建视图「本月可发布」：筛选 优先级 = P0，按素材状态分组。

**内容发布表**：

- 新建视图「本周内容」：按发布周期筛选。
- 新建视图「平台看板」：看板按平台分组。
- 新建视图「待制作素材」：筛选 视觉素材 = 待整理。

**产品与报价**：

- 新建视图「对外报价」：隐藏「渠道内部价」，仅保留产品名称、适用范围、对外价格、交付标准、周期、修改轮次。
- 新建视图「渠道内部价」：隐藏对外营销说明，仅Howard和Brian可见，严禁截图外发。
- 新建视图「多淼联合服务」：筛选 适用范围包含 苏州 或 多淼。

## 第三步：仪表盘（替代网页版总览，约 5 分钟）

多维表格左下角「仪表盘」→ 新建：

- 统计卡：启动准备完成率、基础校验完成率
- 柱状图：询盘记录按状态分布
- 列表：任务交接表中状态 = 待接手 / 待补充 的记录（谁卡着谁，一眼看到）

## 第四步：自动化提醒（替代「实时同步 + 催办」，约 10 分钟）

先建一个两人小群「元晟传媒作战群」。然后在多维表格「自动化」里配 4 条规则：

1. **交接推送**：当「任务交接」新增记录且状态 = 待接手 → 发送飞书消息给「接手人」字段的人。
2. **补充回传**：当状态变更为「待补充」→ 通知发起人（Howard）。
3. **每日 09:25 定时**：向群里发「今日任务」视图链接，配合 09:30 对齐。
4. **每日 17:55 定时**：向群里发「每日五问」表单链接，催复盘。

这就实现了网页版做不到的：**关屏也能收到推送**。

## 第五步：文档库迁移

1. 云文档新建文件夹「元晟传媒文档库」，设为仅两人可见。
2. 先导入 `07-文档库.csv`，把本地文件变成可追踪的文档索引。
3. 20 个核心文档按「文档库」逐个导入飞书文档；已有 `feishu/` 共享版的内容可优先复制进去。
4. 每导入一个文档，就把飞书文档链接填回「文档库」。
5. 在「任务交接」「案例库」「内容发布表」「产品与报价」中，把相关字段关联到「文档库」记录，避免任务只有文件名没有上下文。
6. **敏感文档**（`02-channel-internal-pricing.md` 渠道内部价）：单独设置权限，关闭「允许分享」，仅两人可读。

不建议把所有正文复制到多维表格单元格。多维表格负责状态、关系和提醒；正文内容放飞书文档，后续才能评论、标注、修改。

## 第六步：文件库与协同的关系配置

最少要建立 4 条关联：

| 表 | 字段 | 关联到 | 用途 |
| --- | --- | --- | --- |
| 任务交接 | 关联文档 | 文档库 | Brian接到任务后能直接打开文案、说明或素材要求 |
| 案例库 | 关联文档 | 文档库 | 每个案例能找到包装原则、首月内容和公开边界 |
| 内容发布表 | 关联案例 | 案例库 | 每条内容知道自己基于哪个案例 |
| 产品与报价 | 关联文档 | 文档库 | 每个服务能追溯报价和交付标准 |

这样飞书工作台才不是“任务清单”，而是“任务 + 文件 + 案例 + 报价 + 内容”的协同系统。

## 权限与安全（对应你担心的公网问题）

- 多维表格右上角「分享」→ 关闭「允许通过链接访问」，仅邀请Brian一人为「可编辑」。
- 数据在飞书租户内，手机 App 原生同步，无自建服务器、无公网暴露面。
- 网页工作台可继续本地留着做「文档阅读器」用，或直接退役。

## 迁移后的日流程（与原来一致）

1. 09:25 群里收到今日任务推送 → 09:30 两人看「今日任务」视图对齐。
2. Howard定稿文案 → 「任务交接」加一条 → Brian自动收到推送。
3. Brian拖看板卡片流转状态；缺文案就改成「待补充」，Howard收到通知。
4. 询盘随手用表单登记。
5. 17:55 收到催复盘 → 各填「每日五问」表单。
