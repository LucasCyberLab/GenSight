# 元晟传媒 (Gensight) - 独立站技术学习计划与两人协同 SOP

> 版本：2026-08 实施版  
> 目标：7 天内攻克 No-Code 独立站搭建全流程，建立标准化交付 SOP。  

---

## 1. 7 天速成学习计划 (No-Code 建站 + AI 视觉 + 英文 Copywriting)

### Day 1 ~ Day 2：No-Code 建站核心技术拆解 (Howard + Brian)
- **重点**：放弃代码思维，掌握可视化建站引擎。
- **Howard**：注册 Shopify 试用账号，掌握 Shopify 后台架构、域名解析、支付配置（PayPal/Stripe 模版）、运费模版配置及基础应用插件。
- **Brian**：学习 Shopify PageFly / Shogun 或 WordPress Elementor 拖拽排版，掌握网格留白、响应式移动端适配（Mobile-First）。

### Day 3 ~ Day 4：AI 英文营销文案与欧美视觉生成 (Howard + Brian)
- **Howard**：训练 Claude / ChatGPTPrompt 模版——输入产品功能参数，输出符合欧美文化习惯的 Brand Story、Hero Banner 标语、痛点对比表及 FAQ。
- **Brian**：主攻 Midjourney / SD / Flux 生成欧美本土模特图（European & American Lifestyle）、极简 3D 渲染光影感产品场景图与透明底展示图。

### Day 5 ~ Day 7：打造首个虚拟品牌 Demo 样板站 (实操跑通)
- **目标**：选定 1 个品类（如“智能户外储能电源”或“极简智能咖啡机”），完成 1 个 100% 具备大厂品质的演示独立站。
- **产出**：将 Demo 站录屏、截图并打包为《Gensight 出海品牌独立站案例实录》。

## 2. 两人协同交付 SOP (Howard & Brian)

```
阶段 1: 询盘与签约 (Howard主导)
├─ 1.1 15 分钟内响应客户咨询，评估出海品类与目标市场
├─ 1.2 发送《出海独立站产品手册与案例 Demo》
└─ 1.3 确定需求梯队，签署线上协议，收取 50% 订金

阶段 2: 策略定义与素材生产 (双人并发)
├─ Howard (策略与文案):
│   ├─ 2.1 品牌定位与价值主张提取
│   └─ 2.2 使用 Claude 生成全站英文 Copywriting
└─ Brian (视觉与素材):
    ├─ 2.3 生成符合欧美审美的主视觉 Banner
    └─ 2.4 使用 MJ/Flux 精修 10 款主力产品场景图

阶段 3: No-Code 建站与整合 (两人协同)
├─ 3.1 Shopify/WP 站点搭建与页面组装 (Howard配后台，Brian做排版)
├─ 3.2 移动端 (Mobile) 与 Web 端双端适配测试
└─ 3.3 对接域名、支付接口、物流模版与基础 SEO

阶段 4: 交付验收与后续转化 (Howard主导)
├─ 4.1 远程演示站点，提交客户验收并收取 50% 尾款
├─ 4.2 交付站点管理权限与 1 小时使用培训视频
└─ 4.3 引导客户签署《海外广告视觉与素材月包 (¥5,680/月)》
```
