# GenSight 当前运营基线

> 生效日期：2026-08-04  
> 用途：这是当前业务和日常执行的唯一判断入口。若其他历史文档与本文冲突，以本文为准，直到下一次明确更新。

## 1. 当前唯一主线

GenSight 当前以 **跨境电商与独立站视觉素材代制作** 为主线：

- 平台：Amazon、美客多、Shopee、TikTok、SHEIN、Shopify。
- 客户：已有产品与销售基础、视觉素材影响点击或转化的跨境卖家、工贸一体企业和 DTC 品牌。
- 核心产品：体验包、单 SKU Listing 开款包、跨平台素材月包；需要时提供 A+、多语种和 TikTok 微动效增配。
- 当前目的：用可展示的 Demo、定向触达和小额体验包，验证“视觉素材代制作 → 月包续费”的成交路径。

## 2. 不作为当前主线的事项

- 国内 Logo / VI、PPT、效果图、品牌全案：可以承接自然到来的零星订单，但不作为本周主动获客、内容发布或案例展示的主要方向。
- 独立站全案：保留为高客单机会与 Demo 展示方向，在跨境视觉素材月包获得稳定验证前，不作为日常交付重心。
- 本机 `archive/app.js` 工作台：不再作为日常协同工具。

这不是否定历史积累，而是避免两人把有限精力同时投入多条获客线。

## 3. 每日运行规则

### 数据与协作

- **飞书多维表格是唯一数据源**：任务、负责人、交接、线索、报价、成交、交付状态和晚间复盘必须记录在飞书。
- GitHub Pages 只提供 SOP、报价、案例和战略上下文，不保存业务状态。
- 晨会只确认每人 1–3 个可验收输出；发生战略选择时，放到固定复盘时段，不在执行时讨论。

### 优先级

1. 已预付客户的交付与风险处理。
2. 跨境目标客户的有效触达和询盘跟进。
3. 跨境视觉案例、Prompt 和交付模板的资产沉淀。
4. 国内设计机会单，只在不挤占前三项时承接。

## 5. 每周唯一目标的写法

每周只写一个结果，而不是一串待办。例如：

> 完成 1 个跨境视觉 Demo 的案例包装，并向 25 个目标商家发出带诊断的定向触达，获得至少 3 个有效回复。

对应飞书需要有：负责人、截止日、验收标准、关联资料、下一步动作和状态。
