# OPC 09 · 经营复盘与瓶颈识别

> 状态：**运营期循环**（周复盘必读，日复盘见飞书 T06）  
> 数据权威来源：**飞书 T06 晚间复盘 + T05 询盘 + T10 成交**

---

## 1. 日复盘（飞书 T06）

每日 21:00 填写，字段对齐 [每日执行 SOP](./daily-action-and-review-guide.md) 四问：

1. 今日亮点与战果（进账、触达、有效回复）  
2. 今日瓶颈（交付/沟通/工具）  
3. 新假设与机会（平台/类目/报价）  
4. Stop / Keep / Start → **次日 Top 3 写回 T04**

GitHub Pages **不保存**日复盘内容。

---

## 2. 周复盘（周五或周日，30 分钟）

### 必看三数（从飞书汇总）

| 指标 | 来源 | 健康参考（可调） |
| --- | --- | --- |
| 有效触达 | T06 / T05 | 周 ≥25 次定向触达 |
| 有效回复 | T05 | 周 ≥3 个深度对话 |
| 现金流 | T06 + 收款记录 | 体验包或月包订金 ≥1 单 |

### 每周只写一条「唯一主线」

格式见 [当前运营基线](./00-current-operating-baseline.md) §5。写入：

- 飞书 T04 本周首行或单独「周目标」视图  
- `portal/site-config.json` → `weeklyGoal`（同步到 Pages 首页展示）

---

## 3. 瓶颈识别（Stop-loss）

| 信号 | 动作 |
| --- | --- |
| 连续 2 周触达无有效回复 | 换平台或换触达话术，复盘 Demo 是否够锋利 |
| 交付反复返工同一规格 | 补平台 checklist，沉淀到 T08/Prompt 库 |
| 国内机会单挤占跨境交付 | Stop 主动接国内单，Keep 已预付交付 |
| 两人在多个计划文档间争论「今天做什么」 | 回到基线 + 飞书 T04，不开新文档 |
