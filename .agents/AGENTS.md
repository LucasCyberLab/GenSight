# 元晟传媒 (Gensight) - Agent Rules & OPC Methodology Guidelines

本项目已全量安装并采用 **OPC 方法论 (One-Person Company Methodology / 一人企业方法论)** 进行项目战略、业务模式及日常运营规划。

## 1. 核心原则与工作流规范

1. **统一文档落盘目录**：所有 OPC 方法论分析与规划产物统一存放于 `opc-doc/` 目录。
   - `opc-doc/state/current-stage.json`：记录项目当前所处 OPC 阶段与跳步标记。
   - `opc-doc/01-resource-audit.md` 至 `opc-doc/09-dashboard-review.md`：存放各阶段推演成果。
   - `docs/opc-methodology/`：方法论原书章节参考资料。

2. **OPC 技能集 (`.agents/skills/`)**：
   - `opc-orchestrator`: OPC 总编排与流程调控。
   - `opc-resource-audit`: 01 资源盘点（个人/团队资产、杠杆与约束）。
   - `opc-niche-positioning`: 02 利基定位（三环叠加、六维评分与不竞争策略）。
   - `opc-value-proposition`: 03 价值主张（Jobs/Pains/Gains 拆解与选择）。
   - `opc-business-model-design`: 04 商业模式（精益画布 Lean Canvas & 风险假设）。
   - `opc-mvp-designer`: 06 MVP 设计（最小可行性验证与边界）。
   - `opc-conversion-loop`: 07 转化闭环（触达 → 承接 → 成交路径）。
   - `opc-asset-ops`: 08 资产沉淀（复用成果与系统化沉淀）。
   - `opc-dashboard-review`: 09 经营复盘（瓶颈识别与单点突破）。

3. **阶段边界严格管控**：
   - 遵从对话先行、决策由用户做出、单次提问适度的交互原则。
   - 严禁在当前阶段越界讨论后续阶段具体产出。

4. **项目结合点 (Gensight 主线)**：
   - Gensight 为两人协作/一人企业模式，主打 AI 视觉设计、品牌 VI/全案、PPT 及小红书/咸鱼自媒体获客。
   - OPC 规划需与项目现有的 `00`~`18` 业务与运营文档及飞书多维表格协同工作台深度融合。
